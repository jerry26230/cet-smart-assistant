# CET 智能备考助手

软件工程课程项目，基于成熟开源软件 [Anki](https://github.com/ankitects/anki) 的插件机制进行二次开发，不修改 Anki 核心源码。

## 当前阶段：Task 005

通过“工具 → CET 智能备考助手”打开学习计划窗口，填写成绩、目标和学习时间，选择学习重点，点击“保存并生成计划”。显示描述性的分项得分率、待确认的初始关注项及每日分钟分配。默认均衡覆盖，得分率不直接视为能力排名。详见 [Task 004 验证报告与规则](docs/task004-verification.md)。

新增词汇卡片入口，可创建 CET6 卡组、添加正反面词汇卡，并阻止重复添加。详见 [Task 005 实机验证](docs/task005-verification.md)。

## Windows 安装

1. 打开 Anki，选择“工具 → 插件 → 查看文件”（英文界面：Tools → Add-ons → View Files）。以该按钮打开的实际插件目录为准。
2. 关闭 Anki。
3. 将本项目的整个 `cet_smart_assistant` 文件夹复制进该插件目录。
4. 标准安装通常对应 `%APPDATA%\Anki2\addons21\cet_smart_assistant\__init__.py`。自定义数据目录可能不同。
5. 重新打开 Anki，进入用户配置。

不要只复制 `__init__.py` 到 `addons21` 根目录，也不要额外套一层同名目录。

## 运行与验收

1. 确认启动时没有插件错误。
2. 打开“工具”，确认出现“CET 智能备考助手”。
3. 点击菜单，打开“CET 智能备考助手 · 学习计划”窗口。
4. 输入演示数据：总分 470、听力 115、阅读 190、写作翻译 165、目标 500、90 天、每天 120 分钟。
5. 默认选择“均衡覆盖”，点击“保存并生成计划”。上述演示数据的每日计划为词汇 24、听力 32、阅读 32、写作翻译 32 分钟。
6. 可选择“参考初始关注项（小幅倾斜）”或自己确认的专项重点，再保存。选择写作重点时，上述计划为词汇 24、听力 24、阅读 24、写作翻译 48 分钟。
7. 关闭并重新打开窗口，资料和已保存的重点自动回填，计划重新计算。

首次没有资料时各项为空；关闭窗口不会自动保存修改。已有个人资料时请勿为了演示而覆盖，建议在单独的 Anki 测试账户中使用演示数据。修改任一输入会清除旧诊断，保存成功后重新计算。

## 初始画像与学习计划规则

得分率分别为：听力 / 248.5、阅读 / 248.5、写作翻译 / 213。使用原始得分率计算，界面百分比保留一位小数。

- 分项得分率只能描述成绩。缺少各专项分布和题目难度参照，不能直接比较能力；不假定写作分布，也不随意给写作加分。
- 全零不提示关注项；差距不超过 5 个百分点仅说明得分率接近，不表示能力均衡。其余情况将距最低值不超过 5 个百分点的项目提示为“初始关注项（待确认）”。此阈值是项目启发式规则。
- 默认均衡：词汇占 20%，听力、阅读、写作翻译各占约 26.67%。
- 手动确认某专项重点：词汇 20%，各专项先保留 20%，剩余 20% 分给确认重点，重点共占 40%。
- 主动选择参考初始关注项：词汇 20%，各专项 25%，剩余 5% 在关注项之间平分。没有关注项时回退均衡。
- 使用最大余数法取整，总分钟数严格等于每日时间；余数相同时按词汇、听力、阅读、写作翻译顺序分配。极短时长允许部分项目为零，提示隔日轮换。
- 剩余天数按大于 60 天、15～60 天、最多 14 天分别给出基础积累、专项训练、考前整合建议；目标至少 550 分时建议关注难题复盘和表达质量。这些是产品规则，目标和天数只改变练习建议，不额外改变分配比例或预测达标概率。
- 画像与计划每次打开或保存后重新计算，不重复存储。重点保存为 `profile.study_focus`；旧资料缺少此字段时默认均衡。请勿用旧插件覆盖新版带重点的资料。

## 输入与存储规则

- 分数范围：总分 0～710、听力/阅读 0～248.5、写作翻译 0～213、六级目标 1～710。
- 天数必须为 1～3650 的整数，每日分钟数为 1～1440 的整数；这是本阶段的产品输入范围。
- 空值、非数字、无穷值、超范围输入不能保存。分项合计与总分差异超过 10 分时提醒，仍允许保存；10 分是录入提醒阈值，不是考试评分规则。
- 每个 Anki 账户单独保存：`<Anki 账户目录>/cet_smart_assistant/user_data.json`。
- 本机验证路径：`%APPDATA%\Anki2\账户 1\cet_smart_assistant\user_data.json`。
- 保存采用同目录临时文件加原子替换，保留已有练习历史。读取损坏或不支持版本的文件时禁用保存，原文件保持不变。请备份后修复资料文件并重新打开窗口。
- 资料不通过 AnkiWeb 同步，也不包含在本项目 Git 中；备份时请单独复制资料目录。
- 当前记录的是手动输入的剩余天数，尚不自动随日期递减。

## 单元测试

在项目目录执行：

```powershell
python -m unittest discover -s tests -v
```

测试不依赖 Anki 或 Qt。目前 33 项测试覆盖输入与存储、初始提示、重点保存兼容性、计划分配以及卡片服务；遍历 1～1440 分钟和 5 种重点模式共 7200 种组合检查总时间、非负整数与确定性。卡片服务的 8 项测试使用内存替身，另有真实 Anki 验证。Windows 受限沙箱可能限制 Python 临时目录的访问；普通本机终端可运行上述测试。

## 添加词汇卡片

1. 打开助手，点击底部“词汇卡片”。
2. 可点击“创建 CET6 卡组”；直接添加词汇时也会自动创建。
3. 填写词汇及释义，点击“添加词汇卡片”。
4. 关闭助手，在 Anki 的 `CET6 Personalized` 牌组中学习。

词汇最多 200 字符，释义最多 5000 字符，内容按纯文本显示。专用笔记类型为 `CET Smart Assistant Vocabulary`，每条笔记生成一张正反面卡。整个账户内按此类型查重，忽略大小写、首尾及重复空白，并进行 Unicode NFKC 规范化；卡片移到其他牌组后仍可识别。重复词不覆盖原释义。查重针对插件创建的纯文本正面；手动加入 HTML 格式后可能无法识别。

卡片保存在 Anki 集合中，学习资料仍保存在独立 JSON 中。复习和调度由 Anki 管理。与同名筛选牌组或被修改的同名模板冲突时会拒绝操作，不覆盖已有内容。尚无批量词库、音频或自动选词功能。

## PyCharm 编辑方式

在 PyCharm 中打开本项目的“软件工程”目录，编辑对应模块。修改后关闭 Anki，将插件源码复制到 Anki 插件目录，再重启 Anki。资料在账户目录中，与插件源码分开保存。

不要通过 PyCharm 的 Run 直接运行插件入口：`aqt`、主窗口和菜单由 Anki 提供。编辑器若提示无法解析 `aqt`，不代表插件在 Anki 中无法运行。

## 启动失败时检查

- 菜单不出现：核对插件目录层级，确认插件已启用并已重启 Anki。
- 出现 `No module named aqt`：确认是在 Anki 内加载，而不是用普通 Python 执行文件。
- 启动时报错：保存完整错误信息和 Anki 版本，并核对复制的文件是否完整。
- 中文乱码：确保源文件保存为 UTF-8。

## 实现依据

菜单注册使用 `aqt.mw`、`QAction`、`qconnect` 和 `mw.form.menuTools.addAction`；提示框使用 `showInfo`，遵循 [Anki 官方最小插件示例](https://addon-docs.ankiweb.net/a-basic-addon.html)。
