# CET 智能备考助手

基于 [Anki](https://github.com/ankitects/anki) 插件机制开发的离线英语备考助手，为软件工程课程项目。将备考资料、每日学习计划和词汇卡片整合到 Anki 中，复习调度由 Anki 管理。

**目前已实现：资料保存、谨慎的初始学习提示、每日时间分配、专项练习记录、四级 / 六级 / 雅思内置词库、批量导入与查重。**

> “智能”指可解释的规则辅助，学习计划采用规则；另提供可选 AI 词汇用法生成，不预测考试成绩。雅思目前只支持词汇学习，学习计划仍面向 CET。

## 功能一览

| 功能 | 当前实现 |
| --- | --- |
| 备考资料 | 记录四级总分、分项成绩、六级目标、考试日期及每日时间；按 Anki 账户保存，剩余天数自动递减 |
| 初始学习提示 | 分项得分率只作描述，关注项需确认，不直接当成能力排名 |
| 每日学习计划 | 均衡、手动重点及同类练习动态反馈；整数分钟之和等于每日预算 |
| 阅读 / 写作训练 | 用户确认困难后推荐方向；12 个原创示例词，阅读语境和写作填空各 12 张卡 |
| 专项练习记录 | 日期、专项、实际用时、可选原始成绩及复盘备注；历史列表与次数 / 时间汇总 |
| 内置词库 | 四级 3815 词、六级 5371 词、雅思 4974 词，离线选择即可建卡 |
| 批量导入 | CSV / TSV / TXT 文件，或直接粘贴 Excel 两列；导入前预览和检查错误 |
| 卡片保护 | 同库查重、保留已有释义、输入转义、模板冲突保护、整批撤销 |
| 验证记录 | 89 项单元测试；真实 Anki 后端批量建卡、重复导入及撤销验证 |

## 安装

### 推荐：直接安装插件包

下载 [CET 智能备考助手 0.1.2 安装包](https://github.com/jerry26230/cet-smart-assistant/raw/refs/heads/main/downloads/cet-smart-assistant-0.1.2.ankiaddon)。在 Anki 桌面版打开 **工具 → 插件 → 从文件安装（Install from file）**，选择 `.ankiaddon` 文件，安装后重启 Anki。随后打开 **工具 → CET 智能备考助手**。

不用解压，也不用安装 Python。已有手动安装版使用相同目录标识，更新同一插件；学习资料位于账户目录，包内不含个人资料。当前为体验改进版本；仅验证 Windows + Anki 26.9.3，不适用于手机端，尚未发布到 AnkiWeb，后续更新需要下载新包安装。

[校验值](downloads/cet-smart-assistant-0.1.2.ankiaddon.sha256) · [打包与验证说明](docs/package.md)

### 源码安装

已验证环境：**Windows + Anki Desktop 26.9.3**。其他版本及平台尚未验证。本项目是桌面插件，不能直接安装到 AnkiDroid 或 AnkiMobile。

1. 下载本仓库（GitHub 页面 **Code → Download ZIP**），解压。
2. 打开 Anki，进入 **工具 → 插件 → 查看文件**，找到当前插件目录，然后关闭 Anki。
3. 将仓库中的整个 `cet_smart_assistant` 文件夹复制到插件目录。
4. 确保包含 `vocabularies` 子目录以及其中的 JSON、授权和来源文件。
5. 重新启动 Anki，打开账户，进入 **工具 → CET 智能备考助手**。

标准安装目录示例：

```text
%APPDATA%/Anki2/addons21/
└── cet_smart_assistant/
    ├── __init__.py
    ├── ui.py
    ├── ...
    └── vocabularies/
        ├── cet4.json
        ├── cet6.json
        ├── ielts_core.json
        └── ...
```

不要把整个仓库套在插件目录里，也不要只复制 Python 文件。更新插件时先关闭 Anki，再覆盖插件文件夹。无需在系统 Python 中安装 PyQt。

## 使用方法

### 1. 生成每日学习计划

打开助手，填写成绩、目标和每日可用分钟数，选择目标考试场次及学习重点，点击 **保存并生成计划**。

目标考试日期只需确认一次，之后每次打开自动计算剩余天数，窗口保持打开时每 30 秒检查是否跨日，学习阶段也随之更新。当前内置已公布的 2026 年笔试日期（6 月 13 日、12 月 12 日），默认推荐最近一场未结束的场次；也可以按学校通知选择自定日期。考试当天显示应试提示，日期过后提醒选择新场次，不自动替换目标。未来日期未公布时不按固定星期推测。旧资料首次升级需要确认日期后保存，原成绩与练习历史保留。详见[自动倒计时说明与官方来源](docs/task009-exam-calendar.md)。

例如每天 120 分钟，默认均衡覆盖时为：词汇 24 分钟、听力 32 分钟、阅读 32 分钟、写作翻译 32 分钟。若自己确认写作是重点，可选择写作重点，此时为 24 / 24 / 24 / 48 分钟。

关闭后再次打开会回填资料。仅关闭窗口不会保存未提交的修改。已有个人资料时不必为了演示重新录入示例成绩。

**为什么不直接按百分比判定弱项？** 写作与客观题的分数分布、评分方式不同，除以满分只统一数值尺度。因此默认采用均衡计划，用户可确认重点；得分率提示只允许主动选择后小幅影响计划。详见[计划与存储规则](docs/planning-and-storage.md)。

### 2. 直接学习内置词库

1. 点击助手底部 **词汇卡片**。
2. 选择 **四级词汇 / 六级词汇 / 雅思词汇**，点击 **使用所选词库（自动建卡）**。
3. 完成后关闭助手，在 Anki 牌组列表中展开 **CET 备考**，进入对应牌组学习。

| 词库 | 单词数 | Anki 牌组 |
| --- | ---: | --- |
| 四级 | 3815 | CET 备考::四级词汇 |
| 六级 | 5371 | CET 备考::六级词汇 |
| 雅思 | 4974 | CET 备考::雅思词汇 |

无需联网或自己准备词表。同一词库重复选择不会重复建卡，也不会覆盖已有释义。三套词库相互独立，重叠单词在不同词库各有一张卡片。每天出现的新卡数量仍由 Anki 的牌组选项控制。

### 3. 补充自己的词汇

少量词汇可在词汇窗口输入单词和释义，点击 **添加词汇卡片**。大量词汇使用 **批量导入词库（文件 / 粘贴）**：

1. 选择文件，或从 Excel 复制“单词、释义”两列后粘贴。
2. 点击 **预览并检查格式**，查看有效词、文件内重复项和错误行号。
3. 修正全部格式错误后，点击 **导入预览中的词汇**。

CSV 示例（可下载[模板](examples/vocabulary-template.csv)）：

```csv
word,meaning
abandon,v. 放弃；抛弃
abstract,"adj. 抽象的, n. 摘要"
adapt,v. 适应；改编
```

支持 UTF-8 / GB18030 编码，每批最多 10000 条、5 MB。含逗号的 CSV 释义需加双引号。单词最多 200 字符，释义最多 5000 字符。自备词汇保存在 `CET6 Personalized` 牌组；已有卡片在导入时检查并跳过。

### 4. 记录专项练习

在助手中点击 **练习记录**，选择日期与专项，填写用时、练习名称，得分和满分可同时留空，点击 **保存练习记录**。下方显示历史，以及每个专项的累计次数和分钟数。保存后重复点击不会追加记录；修改输入后可记录下一次练习。

记录与个人资料按 Anki 账户保存在本机。列表展示最近 500 条，汇总覆盖全部已识别记录；旧格式记录保留并提示，不强行转换。不同专项或难度的原始成绩不直接比较，需要动态调整时，另填写可比组并主动确认，选择动态模式后按同组趋势计算。详见 [Task 006 验证](docs/task006-verification.md)。

### 5. 按阅读或写作困难练词汇

在助手主窗口点击 **阅读语境 / 写作表达训练**，选择最近遇到的困难。系统推荐阅读语境或写作表达方向，你也可以手动更改；先预览，再点击添加所选方向的 12 张训练卡。随后在 **CET 备考 → 专项训练** 中学习。

阅读卡练语境义，写作卡练搭配填空和主动表达。示例包覆盖 12 个词，共 24 张卡；由本项目 AI 辅助编写，非真题，未作考试词频统计。长难句、文章结构等问题会提示相应练习，不将低分一概归因于词汇。当前尚未根据历史记录自动调整推荐。[功能与验证详情](docs/task007-training.md)

### 6. 根据新练习动态调整计划

在“练习记录”填写**可比组名称**，确认题型、难度、评分方式可比后勾选“纳入趋势”。回到主窗口，学习重点选择 **根据近期同类练习动态调整**，点击 **保存并生成计划**。

只比较最近 28 天内同一专项、同组、同满分、同题量的记录。每组至少 6 个不同练习日，比较前后各 3 日；下降达到 5 个百分点才考虑增加专项时间。数据不足或趋势冲突时保留均衡覆盖，不比较不同专项的绝对分数。页面显示趋势与分配依据；新增记录后重新生成即可更新。详见 [动态规则与验证](docs/task008-feedback.md)。

[工程说明与系统架构](docs/engineering-delivery.md)包含需求、模块、算法和验证记录。

## 数据与词库来源

- 学习资料保存在当前 Anki 账户目录的 `cet_smart_assistant/user_data.json`，不随本仓库分发，也不通过 AnkiWeb 同步。请单独备份。
- 卡片保存在 Anki 集合中，使用 Anki 自身的备份与同步机制。
- 内置数据来自 [WordTyper Vocabularies](https://github.com/grhliu/wordtyper-vocabularies)，上游声明派生自 [ECDICT](https://github.com/skywind3000/ECDICT)。三份数据采用 MIT 授权；原始 [LICENSE](cet_smart_assistant/vocabularies/LICENSE)、[NOTICE](cet_smart_assistant/vocabularies/NOTICE.md) 与[固定来源版本和校验摘要](cet_smart_assistant/vocabularies/provenance.json)随项目保留。
- 内置词表是社区备考参考资料，不是官方认证的完整考纲，也不保证覆盖所有考点。

## 开发与验证

普通 Python 环境运行单元测试，无需安装 Anki 或 Qt：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q cet_smart_assistant
```

目前 89 项测试通过；学习计划测试还遍历 1～1440 分钟 × 5 种模式的 7200 种组合。`tests/verify_anki_backend.py` 需在具有兼容 Anki Python 包的环境运行，只创建临时测试集合。真实后端验证了 14160 张卡片、重复导入、每套一次撤销及卡面生成。`tests/verify_exam_ui.py` 在真实 Qt 中验证日期保存、重新打开、模拟跨日、未保存输入保护和过期提示。Qt 词库选择与预览已做离屏测试；最新批量界面尚无桌面截图验收。

编辑器可使用 PyCharm。不要直接运行插件入口 `__init__.py`；`aqt` 由 Anki 提供。修改代码后须复制插件并重启 Anki。

## 单词用途与可选 AI

已有词汇卡背面新增阅读语境、写作搭配、条件式改写与易错提示。内置 16 个词，未覆盖的词不随意贴高频标签。助手内点击 **单词用途 / AI 用法助手**，或在复习答案底部打开当前词的用法；填写兼容 Chat Completions 的 API 地址、模型和 Key，按需生成，核对后再保存。密钥只留当前窗口，不写入磁盘；无需 API 也能使用离线功能。详见[配置、用法与验证边界](docs/word-usage-ai.md)。

## 当前边界与下一步

- 已支持专项练习历史与同类练习动态计划；已接入可选 AI 词汇用法生成，尚未接入自动选词、音频和综合学习顾问。
- 计划基于可解释规则，尚未用学习效果数据校准；不承诺提分幅度。
- 考试日期表离线维护，未公布的新场次需要更新插件或手动选择日期；倒计时依赖本机日期。
- 查重适用于插件创建的纯文本正面；手动改为 HTML 格式后可能无法识别。
- 原计划的核心功能已连通；公开仓库提供备考功能、安装使用说明、算法与验证文档。

## 常见问题

**菜单不出现：** 检查目录层级、插件是否启用，以及是否重启 Anki。

**提示缺少 aqt：** 请在 Anki 内使用插件，不要用普通 Python 直接启动入口。

**词库完整性校验失败：** 重新复制整个插件目录，尤其是 `vocabularies` 子目录。

**牌组或模板冲突：** 插件不会覆盖被修改的同名模板或同名筛选牌组，请先在 Anki 内检查冲突。

**导入报错：** 可能已有部分内容写入。可在 Anki 中撤销本批操作，或重试，已有词汇会跳过。

## 新版词卡外观

词汇复习正面采用单词标题和回忆提示；翻面后显示释义、学习方向、阅读语境、写作示例与有条件的表达替换。窄窗口采用单列布局，支持 Anki 夜间模式。来源可展开查看，答案底部可打开用法 / AI 助手。

更新插件后重启 Anki，现有内置词卡即可使用，无需重新导入。样式仅在插件运行时生效，不修改笔记字段、模板或复习调度。自行修改过的模板保留原显示，附加用法区；未标注词仍明确提示暂无专项用法。

## 今日任务与双轨练习

先保存并生成计划，点击 **开始今日任务 · 阅读识别 / 写作运用**。词汇与听力给出预算内的行动提示，完成后手动确认；阅读与写作各选择 1～3 个示例词，先作答、显示参考，再自评“还不会 / 不熟练 / 本次独立完成”。作答草稿自动保存在当前账户本机，切换或关闭后可恢复；最多 5000 字，不发送 AI。

同一个词的阅读与写作分别记录。按该方向最近一次自评排序：还不会、未练过、不熟练、本次独立完成；同档先推荐较早练习的词。当天首次打开后固定任务和预算，修改计划次日生效，不刷新已完成任务。误点可撤销当天本项评价后重评，草稿保留；重开自动定位第一项未完成任务，可点击“下一项未完成”继续。完成表示做过练习，不等于掌握；原有同类成绩趋势和 Anki 调度不受影响。

当前使用 12 个原创示例词，非真题；不会自动抽取 Anki 到期词、播放听力材料或批改作文。专项分钟数包含短练习与用户自行安排的复盘，不是计时器测得的用时。记录放在当前账户 user_data.json 的 daily_tasks 中，仅本机保存，不随 AnkiWeb 同步。

详见[规则与验证](docs/daily-tasks.md)。

## 错因与换语境复练（0.1.2）

今日任务显示参考答案后，可以选择“词义 / 语境”“搭配 / 介词”“词形 / 语法”或“想不出表达”，再点“还不会 / 不熟练”。错因可跳过；点“本次独立完成”不记录错因。下一次该方向选中这个词时，根据最近一次未熟练记录给出检查提示。

每日训练的 12 个词现在各有两组原创语境，共 24 组、48 道阅读 / 写作练习。完成后再次选中时交替出题；未完成不推进轮换。提示是按用户自评给出的检查建议，不是自动诊断。题目仍为原创示例，非真题；原有批量专项导入仍为基础 24 张卡，新语境用于每日任务。
