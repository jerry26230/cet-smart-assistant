LEARNING LOOP

一次复习，连起下一次进步。

PLAN → PRACTICE → ADJUST
PHASE 01 / PLAN

按考试日期排任务

设置考试目标与每天可学时长，查看当前阶段的复习重点。

PHASE 02 / PRACTICE

在 Anki 中完成练习

复习词汇卡片，结合阅读与写作专项练习理解词语用法。

PHASE 03 / ADJUST

用反馈调整方向

记录完成情况与专项表现，再根据反馈安排下一阶段学习。
