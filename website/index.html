Designed for steady study

备考安排有依据，
每天练习有去处。

把零散的目标和练习收进一个熟悉的复习工具。建议可以调整，练习过程由你自己确认。

从目标到每日时间表

保存考试日期、每日可用分钟数和学习重点。倒计时自动更新，学习时间按分钟预算分配，合计与每日预算一致。

词汇放回语境里练

选择四级、六级或雅思词库自动建卡，也可批量导入。阅读语境和写作搭配分开练，不把近义词当机械替换。

记录练习，再看同类变化

记录专项、用时和可选成绩。只有确认题型、难度与评分可比后，才用同类练习趋势小幅调整计划。

One word, two directions

一个词，先判断
它适合怎么用。

比如 abandon：阅读时练习从上下文识别“放弃”；写作时看固定搭配是否自然。学习方向由语境决定，不给单词随意贴“高频”标签。

切换示例，看看阅读理解和主动表达如何分开练。例句为项目原创教学示例，非真题。

abandon/ əˈbændən / · v.
本机用法示例
阅读 · 从上下文理解
The team abandoned the plan after reviewing its costs.
团队评估成本后放弃了计划。
关注 abandon + plan 的语境，识别“放弃计划”，而不是只背一个中文释义。
示例内容来自项目内置用法条目；未标注的词会提示暂无专项用法。
A clear study loop

从填写一次，到持续复盘。

先用简单规则建立节奏，再用自己确认过的练习记录提供反馈。不用每次重新填写倒计时。

01 / 设定

写下考试目标与时间

录入目标场次、每日可用分钟数和自己确认的关注方向。日期保存后，剩余天数随本机日期更新。

02 / 开始

按预算完成今天的练习

按计划安排词汇、听力、阅读和写作翻译。今日任务能保存草稿，并对阅读与写作分别自评。

03 / 调整

用可比练习观察变化

记录同类练习后查看趋势。样本不足或方向不一致时，计划保持均衡；不同专项分数不直接比较。

Optional AI vocabulary guide

需要时再启用 AI，用法由你核对。

可填写兼容 Chat Completions 的 API 地址、模型和 Key，为其他词生成阅读语境、写作搭配和条件式替换建议。生成内容需自己检查后再保存；不用 AI 也能使用离线词库与计划功能。

Get started

几分钟安装，
从 Anki 开始。

当前插件包版本为 0.1.5。推荐直接安装 `.ankiaddon`，无需单独安装 Python。请确认使用的是 Anki 桌面版。

下载插件包 ↓
1

下载插件文件

保存 `cet-smart-assistant-0.1.5.ankiaddon`。

2

从 Anki 安装

打开 Anki：工具 → 插件 → 从文件安装，选择刚下载的文件。

3

重启并打开助手

重启 Anki 后，从 工具 → CET 智能备考助手 打开功能窗口。

适用范围与说明

  • 这是 Anki 桌面版插件；项目在 Windows + Anki 26.9.3 上验证，手机端不可直接安装。
  • 内置词表是社区备考参考资料，不是官方完整考纲；示例句不是历年真题。
  • 阅读、写作自评不代表掌握程度或提分预测；AI 生成建议需自行核对。
  • 学习资料保存在当前 Anki 账户本机；插件包不包含个人成绩或 API Key。
Good to know

使用前，
先看这几件事。

透明说明功能能做什么，也说明它目前的边界。

不配置 AI 能正常使用吗？

可以。词库、每日计划、练习记录和已内置的词语用法都能离线使用。AI 只用于用户主动请求生成额外用法。

计划会根据分数自动判断我的弱项吗？

不会把写作等主观题得分率和客观题直接排名。默认均衡安排；用户确认重点后可以调整。动态反馈只比较用户确认可比的同类练习。

它会自动批改作文或预测四六级成绩吗？

目前不会自动批改作文、播放听力材料或预测考试成绩。阅读与写作训练提供练习素材和自评记录。

如何查看源码、规则和词库来源？

可在 GitHub 查看源代码、词库来源与授权、计划规则和验证记录。打开项目仓库 ↗
