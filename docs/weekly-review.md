# 本周学习回顾（0.1.4）

主窗口新增入口，按本机日期统计今天及过去 6 天（共 7 天）的每日任务。显示有完成项目的天数、完成任务项/总数、阅读与写作各自练习和三种自评次数、非“独立完成”时用户主动选择的错因及下一步复练建议。

无每日任务数据时给出入门提示。只使用已有记录，旧文件无需迁移。不自动补记或推测实际学习时长。结果是学习活动回顾，不是考试能力或掌握率评价；跨方向次数独立展示。损坏数据沿用现存安全处理，不覆盖原文件。

验证：91 项 unittest 通过，包括空数据、严格七日窗口、跨日、两方向分开计数和错因；真实 Qt 对话框验证格式及免责说明，截图已检查；0.1.4 使用本机 Anki AddonManager 解析 manifest，解包检查全模块与三套词库。
