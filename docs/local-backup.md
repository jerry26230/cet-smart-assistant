# 本机学习资料备份

从版本 0.1.5 起，主窗口增加“备份本机学习资料”。这项功能用于把插件保存在当前 Anki 账户目录中的学习记录导出到用户选择的 ZIP 文件，减少重装系统或迁移账户时手工寻找文件的步骤。

## 备份内容

压缩包只包含存在的插件 JSON 文件：

- `user_data.json`：考试目标、学习计划、专项练习历史、每日任务结果与草稿等本机资料。
- `word_guides.json`：用户确认保存的单词用法建议。
- `backup_manifest.json`：备份格式版本、生成时间和文件清单。
- `README.txt`：备份范围与手动恢复说明。

压缩包不含 API 密钥。当前密钥只在用法助手窗口内使用，不写入本机文件。压缩包也不含 Anki 卡片、牌组和复习进度；这些由 Anki 集合管理，需要另行使用 Anki 的集合备份。ZIP 文件未加密，可能包含个人成绩和学习草稿，应保存在自己信任的位置。

## 操作步骤

1. 打开 Anki 桌面版并进入需要备份的账户。
2. 从“工具”菜单打开“CET 智能备考助手”。
3. 点击窗口下方的“备份本机学习资料”。
4. 选择 ZIP 文件的保存位置和名称，确认后等待成功提示。
5. 将文件保存在安全的位置；如需迁移到其他设备，可通过用户认可的方式自行复制备份文件。

如果账户目录中既没有 `user_data.json` 也没有 `word_guides.json`，系统会提示没有可备份的资料，不生成空压缩包。导出采用临时文件写入后再替换目标文件；创建失败时原有备份保持不变。

## 恢复步骤

1. 先关闭 Anki，并确认目标账户目录。
2. 解压 ZIP，确认包含需要恢复的 JSON 文件。
3. 先把目标目录中同名文件另存一份，再将需要恢复的文件复制到 `<Anki账户目录>/cet_smart_assistant/`。
4. 重新打开该账户和插件，确认资料正常读取。

恢复某个 JSON 会替换该文件当前的全部内容。只想恢复部分数据时，应先保留当前文件并手动合并 JSON；不要在 Anki 正在运行时直接替换文件。恢复卡片和复习安排时，请使用 Anki 自身的集合恢复功能。

## 验证

自动化测试覆盖两类资料都存在、只有单个资料文件、资料内容保真、清单与恢复说明、空目录不创建备份，以及写入替换失败时保留已有备份并清理临时文件。当前 ZIP 导出不改动源文件，也不自动上传或同步备份。
