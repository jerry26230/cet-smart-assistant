# 本机学习资料备份

从版本 0.1.5 起，主窗口提供“备份本机学习资料”；0.1.7 增加 ZIP 检查、恢复预览和安全恢复。功能用于迁移账户或重新安装系统时带回插件学习资料。

## 备份内容

压缩包只包含存在的插件 JSON 文件：

- `user_data.json`：考试目标、学习计划、专项练习历史、每日任务结果与草稿等本机资料。
- `word_guides.json`：用户确认保存的单词用法建议。
- `backup_manifest.json`：备份格式版本、生成时间和文件清单。
- `README.txt`：备份范围与恢复向导说明。

压缩包不含 API 密钥。当前密钥只在用法助手窗口内使用，不写入本机文件。压缩包也不含 Anki 卡片、牌组和复习进度；这些由 Anki 集合管理，需要另行使用 Anki 的集合备份。ZIP 文件未加密，可能包含个人成绩和学习草稿，应保存在自己信任的位置。

## 操作步骤

1. 打开 Anki 桌面版并进入需要备份的账户。
2. 从“工具”菜单打开“CET 智能备考助手”。
3. 点击窗口下方的“备份本机学习资料”。
4. 选择 ZIP 文件的保存位置和名称，确认后等待成功提示。
5. 将文件保存在安全的位置；如需迁移到其他设备，可通过用户认可的方式自行复制备份文件。

如果账户目录中既没有 `user_data.json` 也没有 `word_guides.json`，系统会提示没有可备份的资料，不生成空压缩包。导出采用临时文件写入后再替换目标文件；创建失败时原有备份保持不变。

## 恢复步骤

1. 打开 Anki 桌面版并进入目标账户，在工具菜单打开 CET 助手。
2. 点击“恢复本机学习资料”，选择助手生成的 ZIP。
3. 查看预览中的生成时间、文件大小以及将替换、新增或保留的文件。格式错误、内容损坏或不兼容的 ZIP 会被拒绝。
4. 如果当前账户已有学习资料，选择恢复前备份 ZIP 的保存位置。助手先写入该备份，成功后才继续恢复。
5. 阅读确认框中的文件清单和目标位置，确认后执行恢复。ZIP 没有的文件不会删除或覆盖。
6. 成功后关闭并重新打开助手以重新读取资料。如需撤销，可用助手再次恢复刚才生成的“恢复前资料”备份。

恢复会替换 ZIP 中列出的文件的全部内容。每个目标文件以同目录临时文件原子写入；发生写入错误时会尝试把已写入文件回滚到恢复前内容。恢复前 ZIP 会保留，供进一步手动恢复。卡片和复习安排仍由 Anki 集合管理，请使用 Anki 自身的集合备份与恢复功能。

## 验证

自动化验证覆盖两类资料导出、部分文件备份、备份清单与恢复说明、无资料时拒绝空备份、ZIP 预览、格式和 JSON 校验、恢复前保护、未包含文件保留，以及多文件恢复中途失败的自动回滚。ZIP 不加密；导出与恢复都不会自动上传或同步资料。
