# 学习计划与存储规则

## 初始画像与学习计划规则

得分率分别为：听力 / 248.5、阅读 / 248.5、写作翻译 / 213。使用原始得分率计算，界面百分比保留一位小数。

- 分项得分率只能描述成绩。缺少各专项分布和题目难度参照，不能直接比较能力；不假定写作分布，也不随意给写作加分。
- 全零不提示关注项；差距不超过 5 个百分点仅说明得分率接近，不表示能力均衡。其余情况将距最低值不超过 5 个百分点的项目提示为“初始关注项（待确认）”。此阈值是项目启发式规则。
- 默认均衡：词汇占 20%，听力、阅读、写作翻译各占约 26.67%。
- 手动确认某专项重点：词汇 20%，各专项先保留 20%，剩余 20% 分给确认重点，重点共占 40%。
- 主动选择参考初始关注项：词汇 20%，各专项 25%，剩余 5% 在关注项之间平分。没有关注项时回退均衡。
- 使用最大余数法取整，总分钟数严格等于每日时间；余数相同时按词汇、听力、阅读、写作翻译顺序分配。极短时长允许部分项目为零，提示隔日轮换。
- 剩余天数按大于 60 天、15～60 天、最多 14 天分别给出基础积累、专项训练、考前整合建议；目标至少 550 分时建议关注难题复盘和表达质量。这些是产品规则，目标和天数只改变练习建议，不额外改变分配比例或预测达标概率。
- 画像与计划每次打开或保存后重新计算，不重复存储。重点保存为 `profile.study_focus`；旧资料缺少此字段时默认均衡。请勿用旧插件覆盖新版带重点的资料。

## 输入与存储规则

- 分数范围：总分 0～710、听力/阅读 0～248.5、写作翻译 0～213、六级目标 1～710。
- 天数必须为 1～3650 的整数，每日分钟数为 1～1440 的整数；这是本阶段的产品输入范围。
- 空值、非数字、无穷值、超范围输入不能保存。分项合计与总分差异超过 10 分时提醒，仍允许保存；10 分是录入提醒阈值，不是考试评分规则。
- 每个 Anki 账户单独保存：`<Anki 账户目录>/cet_smart_assistant/user_data.json`。
- 本机验证路径：`%APPDATA%\Anki2\账户 1\cet_smart_assistant\user_data.json`。
- 保存采用同目录临时文件加原子替换，保留已有练习历史。读取损坏或不支持版本的文件时禁用保存，原文件保持不变。请备份后修复资料文件并重新打开窗口。
- 资料不通过 AnkiWeb 同步，也不包含在本项目 Git 中；备份时请单独复制资料目录。
- 当前记录的是手动输入的剩余天数，尚不自动随日期递减。
