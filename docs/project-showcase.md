# 项目展示页

网站页面位于 `website/index.html`，以单文件静态页面展示 CET 智能备考助手的实际功能、学习流程、词汇用法示例、安装步骤和当前适用边界。页面里的计划数字、词库数量、插件版本及验证结果来自项目 README 与现有验证记录；示意计划和原创例句均明确标注，不代表真实学习数据或真题。

## 本机预览

在项目根目录运行：

```powershell
python -m http.server 8000 --directory website
```

然后打开 `http://127.0.0.1:8000/`。页面无需安装依赖，也不加载第三方脚本或字体。

## 交互与可访问性

词汇演示可以在阅读识别与写作运用之间切换，支持左右方向键；页面使用语义化标题、可见焦点样式、窄屏布局和减少动态效果偏好。其他页面导航使用原生锚点和折叠说明。

## 当前边界

网站展示的是 Anki 桌面插件，不是在线备考平台。当前验证环境为 Windows + Anki 26.9.3；移动端、自动作文批改和考试成绩预测不在已实现功能中。词库是社区参考资料，例句为原创示例。
