# 项目展示页

网站页面位于 website/index.html，以深空蓝底色、荧光青色和 Anki 学习控制台的视觉呈现 CET 智能备考助手。首屏背景插画保存在 website/assets/cet-study-observatory-hero.png，为展示页生成的装饰性概念图，不是产品截图。

## 展示内容

页面介绍 CET-4、CET-6 与 IELTS 词库、考试日期驱动的学习计划、阅读与写作语境词汇、动态反馈、可选 AI 配置和 Anki 插件安装方式。首屏控制台明确标为静态界面示意，避免与 Anki 内真实数据混淆。词汇场景可以在阅读识别和写作表达间切换；“good argument → compelling argument”用来说明按语境选择表达，并非一对一替换。

“计划模拟”支持每日学习时长、距考试天数、六级目标分数、均衡/成绩关注/专项优先等选项，实时展示四类学习任务的时间分配和备考阶段建议。基础比例、按分项满分换算得分率、5 个百分点关注阈值及最大余数法均与 `cet_smart_assistant/recommendation.py` 保持一致。成绩关注只是项目启发式提示，不是官方能力判断。网页输入仅在当前页面即时计算，不读取或保存 Anki 数据；演示不模拟依赖练习历史的动态反馈调节。

页面内的功能卡片、资源卡片、模拟说明和页脚均链接到 GitHub README、计划规则、每日任务、专项词汇训练、动态反馈和 AI 配置说明，方便答辩时继续展示实现细节。

## 动效与可访问性

页面使用原生 IntersectionObserver 实现滚动显现和轻量错峰，不加载 GSAP、第三方脚本或远程字体。首屏强调层次与对比，后续章节使用短幅度渐入动效。页面尊重系统“减少动态效果”设置；窄屏下导航、卡片、模拟器和安装区域会切换为单列布局。语义化标题、键盘可操作控件、可见焦点和词汇切换的方向键支持保留。

## 本机预览

在项目根目录运行：

    python -m http.server 8000 --directory website

然后打开 http://127.0.0.1:8000/。页面无需安装依赖。

## 当前边界

网站展示的是 Anki 桌面插件，不是在线备考平台。控制台是静态示意；计划模拟器是网页内基础分配演示。当前验证环境为 Windows + Anki 26.9.3；移动端、自动作文批改和考试成绩预测不在已实现功能中。词库是社区参考资料，例句为原创示例。
