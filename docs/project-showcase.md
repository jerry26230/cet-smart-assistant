# 项目展示页

网站页面位于 `website/index.html`，以单文件静态页面展示 CET 智能备考助手的实际功能、学习流程、词汇用法示例、安装步骤和当前适用边界。页面里的计划数字、词库数量、插件版本及验证结果来自项目 README 与现有验证记录；示意计划和原创例句均明确标注，不代表真实学习数据或真题。

## 现场模拟与项目链接

“现场模拟”区域允许访客调整每日学习分钟数和听力、阅读、写作翻译重点，实时查看词汇与专项分钟分配。计算规则对应 `cet_smart_assistant/recommendation.py` 的基础时间分配；模拟输入只在页面中即时计算，不读取 Anki 账户资料，也不保存。真实计划还会处理目标考试日期、备考阶段、学习重点和动态模式，因此模拟器不替代插件内的完整计划。

功能卡片、模拟器和页脚提供到 GitHub README、计划规则、每日任务、专项词汇训练、动态反馈和 AI 用法说明的直达链接，方便访客从功能介绍继续查看操作步骤、实现规则和验证边界。

## 动效与可访问性

页面参考 [GSAP Skills 的 ScrollTrigger 动效思路](https://github.com/greensock/gsap-skills/blob/main/skills/gsap-scrolltrigger/SKILL.md)，使用原生 `IntersectionObserver` 实现滚动进入视口时的渐进显现，并用 CSS 延迟形成轻量错峰；首屏采用短暂的分组入场效果，模拟计划变化时平滑更新进度条。为保持页面离线可用且无需安装依赖，没有加载 GSAP 或其他第三方脚本。尊重系统“减少动态效果”设置；如果浏览器不支持观察器或 JavaScript 未运行，主要内容仍可阅读。

## 本机预览

在项目根目录运行：

```powershell
python -m http.server 8000 --directory website
```

然后打开 `http://127.0.0.1:8000/`。页面无需安装依赖，也不加载第三方脚本或字体。

## 交互与可访问性

词汇演示可以在阅读识别与写作运用之间切换，支持左右方向键；计划模拟器支持键盘操作的时长滑块、常用时长快捷键和学习重点选择。页面使用语义化标题、可见焦点样式、窄屏布局和减少动态效果偏好。其他页面导航使用原生锚点和折叠说明。

## 当前边界

网站展示的是 Anki 桌面插件，不是在线备考平台。当前验证环境为 Windows + Anki 26.9.3；移动端、自动作文批改和考试成绩预测不在已实现功能中。词库是社区参考资料，例句为原创示例。
