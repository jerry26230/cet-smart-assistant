# Task 004：谨慎初始画像与用户确认的学习计划

日期：2026-09-25。环境：Windows + Anki 26.9.3，Python 3.14 单元测试。

## 设计修正

分项得分除以满分只统一数值尺度，不能消除各分项成绩分布、测量方式和难度差异。本项目没有可用参照分布，因此不据此认定哪项能力更弱，也不人为提高写作分数。

UI 将旧版“相对薄弱项”改为“初始关注项（待确认）”，得分率接近不再表述为能力均衡。为兼容内部调用暂保留 `identify_weakness` 和 `Diagnosis.weaknesses` 的历史名称，其输出仅作为启发式关注项。

## 计划规则

词汇占 20%，三专项各先分配 20% 基础时间，剩余 20% 为机动部分：

| 模式 | 机动部分如何分配 | 120 分钟示例（词汇/听力/阅读/写作） |
| --- | --- | --- |
| 默认均衡 | 三专项平分 | 24 / 32 / 32 / 32 |
| 参考初始关注项，示例为听力 | 总时间的 5% 给关注项，其余 15% 平分 | 24 / 36 / 30 / 30 |
| 用户确认写作重点 | 全部 20% 给写作 | 24 / 24 / 24 / 48 |

初始关注项可有多个，额外 5% 在其中平分；没有提示时回退均衡。百分比是舍入前比例，最终最大余数法分配整数分钟，总和严格等于用户预算。很短的每日时间可能有项目为零，界面提醒隔日轮换。所有比例和阶段阈值均是产品启发式规则，没有实证保证。

目标和剩余天数用于练习建议：60 天以上基础积累，15～60 天专项训练，14 天以内考前整合；目标至少 550 分时提醒难题复盘和表达质量。它们不修改时间比例、不预测达标。这避免把四级成绩和六级目标直接相减后假装得到可校准的能力差距。

`StudentProfile.study_focus` 为可选兼容字段，旧 JSON 自动默认 `balanced`。重点选择、保存和回读已实现；当前用户旧资料可直接打开，无需重写。旧插件不认识新字段，若回退应先备份资料。
