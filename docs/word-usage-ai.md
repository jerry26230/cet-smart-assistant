# 单词用途提示与可选 AI

## 直接在词卡中看用法

更新插件并重启 Anki 后，本插件创建的四级、六级、雅思词库以及 `CET6 Personalized` 词卡，在显示答案时附加用途提示：训练方向、阅读语境、写作搭配、完整句子改写和限制条件。已有卡片直接生效，无需重复导入。提示属于渲染层，不重写原释义，也不修改复习调度。

目前内置 16 词：abandon、forget、good、fantastic，以及原有 12 个训练词。未覆盖的词显示暂无专项标注，可通过 AI 补充；不声称已给 14160 个词分类，也没有真实考试频次统计。

例如 abandon 可以先练阅读识别，但谈放弃计划或习惯时也可用于写作；不能与 forget 机械互换。good 应按语境改为表达具体益处、效果等含义的词，fantastic 带强烈赞赏色彩，不是通用的作文升级词。例句和改写为项目原创教学内容（AI 辅助），并非真题。

词义校核参考：[Cambridge abandon](https://dictionary.cambridge.org/us/dictionary/english/abandon)、[Cambridge forget](https://dictionary.cambridge.org/dictionary/english/forget)。学习优先级和正式作文语体建议是本项目教学判断，不是词典给出的考试排名。

## 配置和使用 AI

入口一：助手底部 **单词用途 / AI 用法助手**。

入口二：正常复习时，词卡答案底部 **查看 / AI 补充这个词的用法**，直接带入当前词。预览卡片时展示用法，但不提供此快捷按钮。

1. 选择或输入英文单词/短语；“查看本机用法”不联网。
2. 填写完整 HTTPS API 地址，例如 `https://api.openai.com/v1/chat/completions`，以及你服务商提供的模型名、API Key。
3. 标准接口使用 `max_completion_tokens`；只支持旧长度参数的兼容服务可选 `max_tokens`。不支持 Responses、Anthropic 等其他原生协议，也不保证所有兼容服务都可用。
4. 点击明确标注发送动作的生成按钮，后台请求一次，结果以只读文本预览。
5. 核对内容后点击 **确认保存这份用法到本机词卡提示**。下次显示同一词答案即使用保存结果；重新生成同词并确认会替换原 AI 提示。

没有 API Key 时，原有离线功能与内置提示可正常使用。插件不自带 API 额度，也不读取其他软件的密钥。服务地址、模型和密钥均不落盘，关闭窗口清除密钥；下次打开需重新填写。

请求只包含所选词和固定教学要求，不读取或上传成绩、练习记录、其他卡片、个人文件。Key 仅用于所填服务地址的认证。服务端如何保存请求取决于用户选择的服务商。仅允许 HTTPS，拒绝重定向，不自动重试；请求 socket 超时 30 秒，响应最多 128 KiB，输出上限 1800 token。服务费用由对应账号承担，token 上限不是固定金额保证。

用户确认的 AI 提示保存在当前 Anki 账户目录的 `cet_smart_assistant/word_guides.json`，不包含密钥。最多 500 词/5 MB，损坏文件不覆盖；这份旁路文件仅在本机使用，不随 AnkiWeb 同步。显示前转义 HTML，模型输出不会作为脚本运行。

接口依据：[OpenAI Chat Completions API](https://developers.openai.com/api/reference/cli/resources/chat)。请求和返回格式与该接口对应，AI 只补充教学内容，不调整规则推荐和 FSRS。

## 验证与限制

- 80 项单元测试通过，包含词义限制、未覆盖词行为、用法文件保护、HTML 转义、最小请求、认证、限流、超时、超大响应、无效/截断输出及重定向保护。
- 真实 Anki 临时集合验证：既有词卡答案增强、原卡字段及复习状态不变、卡片数量不变。
- 真实 Qt 和 Anki TaskManager 验证：生成任务在后台线程，结果在主线程预览；不自动保存，切词清除待保存结果，失败保留旧记录，关闭清除密钥。AI 服务使用替身，不产生 API 费用。
- [隔离测试界面截图](evidence/word-usage-ai-offscreen.png)，无个人数据与密钥。
- 本机已安装并启动 Anki；实机点击检查因检测到用户输入及窗口失效停止，尚未完成当前词卡快捷按钮的桌面端到端点击验收。
- 尚无用户服务商的真实 Key 联调结果，不能宣称真实 API 调用已成功；AI 内容仍需语言准确性核对。

此功能是正式备考功能；本机答辩材料保持独立，不进入公开仓库。
