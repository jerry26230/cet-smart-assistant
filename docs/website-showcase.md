# 项目展示页

展示页是课程答辩与同学了解项目的入口，提供项目能力说明、词汇场景切换和不保存数据的学习计划模拟器。

## 本机预览

在仓库根目录运行：

```powershell
python -m http.server 8000 --directory website
```

浏览器访问 `http://127.0.0.1:8000`。页面为静态文件，无需安装前端依赖。

## 操作方式

- 桌面端可使用顶部主导航跳转到系统能力、词汇场景、计划模拟、学习闭环和项目资料。
- 窄屏下点击“菜单”展开导航；选择栏目、点击页头外区域或按 Escape 会收起菜单。
- 词汇卡可用鼠标选择“阅读识别 / 写作表达”；聚焦任一标签后，可用左右方向键切换，Home 与 End 分别跳到第一个和最后一个标签。
- 计划模拟器可调整每日时长、距离考试天数、目标分数和专项重点；参考分项成绩模式可输入示例成绩。分配结果即时更新，页面不会读取或保存 Anki 账户资料。

页面动效遵循系统的减少动态效果设置。展示页的计划只作规则演示；动态历史反馈需在 Anki 插件中使用。


## 验证记录

2026-10-25 在本机浏览器验证：390px 与 320px 宽度下无横向页面溢出；菜单可展开，点击栏目、菜单外区域及 Escape 均可收起；桌面宽度下原导航保持可见。词汇标签的方向键、Home、End 会同步更新选中内容和焦点。模拟器写作优先示例中 120 分钟正确分配为 24 / 24 / 24 / 48 分钟。浏览器控制台无错误。
