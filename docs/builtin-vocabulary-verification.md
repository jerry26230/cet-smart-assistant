## 验证结果

- 43 项单元测试通过：包含词表规范化、中文编码、CSV 引号及多行字段、错误行、大小限制、重复项、已有释义保护、失败重试、原有资料与计划回归。
- 在 Anki 自带 Python 3.13 和真实 Rust 后端中运行独立临时集合测试，三套完整建卡数量均匹配，再次导入无新增。每套仅一次撤销即可移除该次整批建卡，之后可重新导入。抽取卡片检查 question/answer 正常生成，queue=0、reps=0。可复用测试脚本：`tests/verify_anki_backend.py`；结果：[JSON](builtin-backend-verification.json)。
- 使用真实 Qt 离屏实例检查选择框有三项、默认六级、有效预览可导入、修改文本清除旧预览、格式错误禁止导入。此次未完成桌面截图验收，不将离屏测试称为人工界面验收。
- 当前账户通过原生 API 导入后逐牌组检查卡片数量，与上表一致。实际账户操作前遇到后台 Anki 占用，正常结束本任务启动的后台实例后继续，未绕过数据库锁。

实测发现逐条 `add_note` 数千次会耗尽撤销历史，已改为 `add_notes` 一次批量写入，并将模板、牌组、笔记变更合并为一个撤销操作。发生异常时提示可能部分写入，可撤销或重试；不假称必然全批回滚。
